# Летающее кресло «Царь»

Учебный проект, моделирующий одноместное летающее кресло. Кресло умеет
перемещаться по воздуху и воде, расходовать и пополнять заряд, проверять
возможность преодоления препятствий и возвращать снимок текущего состояния.

## Требования

- Python 3.9 или новее;
- внешние библиотеки не требуются.

Все команды ниже выполняются из корня проекта — каталога, содержащего
`flying_chair.py`.

## Запуск тестов

Запустить весь набор тестов:

```powershell
python -m unittest discover -s tests -t . -v
```

Краткий запуск без вывода каждого теста:

```powershell
python -m unittest discover -s tests -t .
```

Набор содержит 50 тест-кейсов:

- 40 модульных тестов в формате AAA;
- 10 сценарных тестов в формате GWT через тестовую обёртку-пилота.

При успешном запуске итоговая строка содержит:

```text
Ran 50 tests

OK
```

Запустить только модульные тесты:

```powershell
python -m unittest tests.test_module -v
```

Запустить только сценарные тесты:

```powershell
python -m unittest tests.test_scenario -v
```

## Демонстрация

Готовый пример нескольких действий с креслом запускается командой:

```powershell
python demo.py
```

Подробное описание шагов и ожидаемого результата приведено в [DEMO.md](DEMO.md).

## Основные файлы

- `flying_chair.py` — реализация класса и доменных исключений;
- `demo.py` — запускаемый пример работы;
- `SPEC.md` — техническое задание;
- `TEST_CASES.md` — спецификация тест-кейсов;
- `tests/` — модульные и сценарные тесты.
